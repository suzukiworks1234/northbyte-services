Flatten nested Apify Dataset JSON into CSV-ready columns

Have an Apify scraper Dataset with nested fields such as company.location.city or role.title? The Dataset JSON Flattener Actor saves a separate flattened Dataset. You can then export that Dataset to CSV or Excel with Apify's normal export tools.

It does not generate a standalone CSV file, expand arrays, deduplicate rows, or overwrite your input Dataset.

Example: nested input → spreadsheet fields

Input row 
{
  "id": "J001",

Expected flattened row 
{
  "id": "J001",
  "company.name": "Northline Labs",
  "company.location.city": "Leeds",
  "role.title": "Data Analyst"
}

How to convert an existing Apify Dataset

  1. Open the Dataset that contains your scraper's nested JSON and find its Dataset ID.
  2. Open Dataset JSON Flattener on Apify, choose the Input tab, and select the Source Dataset (or supply its ID). Your normal read permissions apply.
  3. Keep the key separator ., or use _ for keys such as company_location_city.
  4. Check the current Pricing panel and set an appropriate run-cost limit before starting. Even an example run can incur a charge.
  5. Once the run succeeds, open its new output Dataset and use Apify's standard CSV/Excel export controls.

When this extra Actor is worth it

If you need just a one-time export of selected nested fields, Apify's native Dataset export with flatten options may be enough. Use this Actor when you want a new, persisted flat Dataset for repeat exports or downstream workflows, or a configurable separator. Arrays remain arrays; key collisions may overwrite values, so inspect a small sample first.

Repeated runs can incur repeated charges; failed or interrupted runs may have partial output. Always check the run status and saved rows. This guide is independent documentation, not affiliated with Apify.
