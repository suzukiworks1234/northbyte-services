# Northbyte Services

Static public-facing website for Northbyte Services.

## Purpose

Northbyte Services provides independent, project-based:

- software development
- Python and workflow automation
- CSV / Excel processing and data cleanup
- testing, verification, and technical documentation

The site is intentionally lightweight and contains no analytics, advertising trackers, or forms.

## Free data-automation guides

- [Flatten nested JSON from an Apify Dataset into CSV-ready columns (no-code)](guides/apify-dataset-nested-json-to-csv.md) — an illustrated walkthrough with sample input/output, realistic limitations, a native-export alternative, and a link to the Apify Actor.

This guide is public documentation, not a paid service offering. Using the linked Apify Actor may incur platform charges; see its current Pricing panel.
