# Northbyte Services

Static public-facing website for Northbyte Services.

## Purpose

Northbyte Services provides independent, project-based:

- software development
- Python and workflow automation
- CSV / Excel processing and data cleanup
- testing, verification, and technical documentation

The site is intentionally lightweight and contains no analytics, advertising trackers, or forms.

## GitHub Pages

The production site is intended to be served from the repository root with GitHub Pages.

Files:

- `index.html` — service overview
- `terms.html` — service terms
- `privacy.html` — privacy information
